# 松间 · 圣多纳释放练习

在线使用（手机、电脑均可）：[打开释放练习](https://yixinstellar1101.github.io/Releasing-Emotions---The-Sedona-Method-/)。无需开启本地电脑；记录保存在当前设备的浏览器中。

双击 **启动.cmd**，在浏览器中打开本地页面（需要 Node.js；当前电脑已安装）。保持启动窗口开启，关闭窗口即停止本地服务。也可以直接打开 **松间-圣多纳释放.html**，这是包含全部样式与脚本的单文件版本，可以单独复制使用。无需安装依赖，不使用 CDN。

- 按原 PDF 第1–2页整理的九类中英情绪总表：409 个词条，保留音标；支持中英文搜索、分类阅读及带入练习。常用感受词另外提供双语快捷选择。
- “主题释放”栏目：按已核对的课程目录整理21个主题，分三周，可搜索或自由选题。每个主题提供三个为本页面编写的觉察角度；不要求按天完成，主题会随草稿、记录和备份保留。
- 自定义情绪、三大想要的自我探索。文字中的关键词只提供候选线索，由使用者确认。
- 五步练习、逐题回答、多轮释放与前后强度观察。“不愿意”“不确定”和没有变化都可以继续。
- 在每轮“此刻，有什么不一样？”这一步，点击“还有一点，再释放一轮”，会保留本轮回答、强度和笔记，并直接回到“我能允许此刻的感受先在这里吗？”。下一轮承接当前强度，继续使用已选情绪与三大想要。
- 根据卡住的原因提供提醒；可暂停并从记录恢复。
- 参考用户提供的 Arthur 摘录，卡住提醒增加“恐惧又来了、对状态自责、情绪反而更多、想让对方改变、允许也很用力、怕放下就是退让”等入口；引导强调回到感受、先问能不能、保留选择与边界。
- “主题释放”内有三项可选实用练习：对轻松释放的期待、目标行动阻力、实现后的好处与担心。填写后选择一个关注点，进入原有五步流程，不自动替使用者选择情绪或三大想要。目标、完整清单及本轮关注会保存到练习文字与记录中。
- 释放记录以“想要控制、想要认同、想要安全”为主分类，可按想要筛选。一次记录可归入多个想要，汇总的是本次各轮实际选过的内容；未确定时单独显示。具体情绪保留为补充，不会被自动推断为某种想要。
- 当前浏览器自动保存草稿与记录，支持搜索、查看每轮回答、单条删除及 JSON 导入导出。已存在的同编号记录不会被导入覆盖；导入新记录时，备份中的最新草稿优先于较旧的暂停快照。
- 按住麦克风按钮约 0.24 秒开始中文转写，松开结束；键盘支持按住空格或回车。转写后可编辑。
- 释放时有叶片、光点和涟漪逐渐散开的动画。点击叶子可单独播放，选择“现在试一下”后会自动播放；可跳过，支持系统“减少动态效果”及“减少动画”偏好。动画不代表实际情绪已经改变。

## 手机上使用

手机与电脑连接同一 Wi-Fi，双击 **手机访问.cmd**，保持窗口开启，在手机浏览器输入窗口列出的局域网地址。如果之前运行过普通启动器，先关闭那个启动窗口再启动手机访问模式。

手机访问模式会在局域网提供静态页面，练习内容仍只保存在使用者自己的浏览器中。它不会同步电脑和手机的记录；需要转移记录时使用导出、导入。

手机布局包含大字号输入、至少44像素的主要触控按钮、底部导航与操作区、全面屏安全区，以及按类别阅读的中英情绪表。输入时会收起底部操作区，避免遮挡键盘。

## 主题释放

从导航进入“主题释放”，选择主题和一个觉察角度，点击“开始这个主题”。接下来仍是原有的五步流程，情绪和三大想要由使用者自己辨认。未结束的旧练习会自动保存为暂停记录。

主题可以重复练习，每轮结束可以直接再来一轮。主题库可继续当前主题，也可查看该主题的历史记录；记录搜索支持主题名称。旧版本的草稿和备份无需转换即可继续使用。

21个主题来自已核对的课程目录。反思提示为本页面编写，不是课程逐字稿，也不表示已经读取完整视频讲解。

## 三项实用练习

- **先松开对释放的期待**：可以把“允许自己轻松释放／一次性释放”作为目标，探索对此的期待、担心或用力。这是可选的预备练习，不承诺一定加速。
- **目标练习：行动阻力**：写一个目标和几项具体小行动，选最有感觉的一项，觉察想到行动时的感受。
- **实现后的好处与担心**：分别写实现目标的好处和担心，选一项回到感受。只写一边也可以，不必制造担心。

从主题页、辨认三大想要时的提示，或“卡住了”提醒中进入。开始前会保存当前练习；如果它尚未完成，完成工具练习后可点“保存并回到刚才的练习”，恢复原来的问题、选择和轮次。工具记录仍按实际辨认的三大想要分类，不根据工具名称推断。

用户摘录的采用与改写说明见“课程资料/Arthur摘录-采用说明.md”。

网页长按麦克风需要 HTTPS（电脑 localhost 例外）且浏览器支持中文语音识别。普通局域网 HTTP 地址可以使用文字练习、动画和记录；语音可改用手机键盘自带的麦克风。也可以将单文件 HTML 发送至手机，在支持运行本地 HTML 的浏览器中打开。

## 语音与数据

建议用 Chrome / Edge 通过启动器的 http://127.0.0.1:8765 打开，允许麦克风权限。语音使用浏览器 Web Speech API；是否可用取决于浏览器、网络、地区和组织策略。部分浏览器即使提供该接口，其语音服务也可能无法连接。无法识别时，页面显示原因并保留打字输入。

页面不保存音频，没有转写后端。语音可能由浏览器交由其在线语音服务处理。文字与记录仅写入当前浏览器的 localStorage；请用同一浏览器和同一地址访问。清除浏览数据、更换浏览器或从文件地址改用 localhost 会使用另一份存储，迁移时可先导出再导入。存储失败会显示提示，可导出当前页面里的数据。

使用 node server.cjs 可以手动启动；更换端口可先设置 SEDONA_PORT。普通模式仅绑定本机 127.0.0.1，--mobile 模式监听局域网；两者都只提供静态文件，不接收或上传练习内容。

## 修改页面

index.html、style.css、enhancements.css、themes.css、practice-notes.css、app.js、emotion-chart.js、theme-data.js 和 practice-notes.js 为可编辑源文件。修改后运行 node build.cjs，可重新生成单文件版本。启动器提供的是这些源文件组成的页面；两种版本功能相同。
