# Arthur 摘录：采用与改写

整理日期：2026-10-29。来源为用户在对话中提供的摘录；以下为去重与改写的使用说明，不是原课逐字稿。

| 采用的要点 | HTML 中的入口 |
| --- | --- |
| 先觉察对轻松释放、一次性释放的期待 | 主题释放 → 实用练习；三大想要页的可选预备提示；卡住提醒 |
| 如果现在就实现，我担心什么 | 对释放的期待；实现后的好处与担心 |
| 目标行动阻力 | 写目标与具体行动，选一项进入现有五步释放 |
| 成功结果的好处与代价分别觉察 | 分列好处与担心，单选关注点后练习；完整清单保存在记录中 |
| 允许不是制造情绪；能不能与愿不愿意分开 | 第一个、第二个释放问题及“允许也很用力”提醒 |
| 回到身体和感受，听直觉估量余感 | 情绪识别与释放时的折叠提示；每轮余感观察 |
| 可以允许恐惧，也可以允许暂时卡住 | “恐惧又来了”“没有感觉”提醒及第一问的反馈 |
| 对疲惫的排斥、自责，也可以是最近的感受 | “对状态自责”提醒；对自己失望的主题角度 |
| 记录获得安全感的方式，再感受想到它的情绪 | “我寻求安全感的方式”主题 |
| 已有的安全、快乐与美好不用被赶走 | “不愿放下”提醒与使用说明 |
| 释放不是对外退让，仍可沟通、设边界和行动 | “怕放下就是退让”“想让对方改变”提醒 |
| 留意外界事件之后对自己的责备 | 自我失望主题与“想让对方改变”提醒 |
| 不以永不再出现、到零或指定状态评价练习 | 每轮观察、“一直没变化”提醒与使用说明 |

## 改写原则

- 合并重复话语，保留能直接练习的问句；不复制聊天中的人名、个案或对关系的推断。
- 允许“可能有想要控制”作为探索，不将所有恐惧、找不到感觉或卡住自动归类为控制。
- 不将“频率、丰盛、已经实现”等表述作为事实或效果保证，也不承诺练习会改变某个人、关系或现实结果。
- 不要求释放到接纳、平静、零分才可以停止；保留暂停、休息、行动及边界。
- 工具练习不覆盖旧练习。旧草稿保存为暂停记录；完成后可恢复原处，原始记录和旧版备份继续兼容。
