    A GENTLE PLACE TO BEGIN

    按自己的节奏，练习放下。

    一段几分钟的自我觉察，也可以只是一次短暂停顿。

    怎样进行一次练习

    1. 写下眼前的一件事，留意身体感觉，标记当前强度。
    2. 用情绪词帮助辨认；选多个、自己填写或选择“暂时说不清”都可以。
    3. 探索有没有想要控制、想要认同、想要安全。它们可能重叠，也可能暂时没有答案。
    4. 依次探索：允许感受存在、能否松开、是否愿意、何时尝试。任何回答都可以继续。
    5. 观察变化，保存记录。没有变化也可以结束；想继续时再做一轮。

    释放的是对某个结果的紧抓。愿望、行动、现实中的安全需要和个人边界都可以保留。

    长按说话与记录

    在输入框旁按住麦克风按钮说话，松开后等待转写完成。键盘可聚焦按钮，按住空格或回车说话。第一次使用需要允许麦克风权限；转出的文字可继续修改。

    建议用 Chrome 或 Edge，通过本目录的“启动.cmd”打开本地页面。中文识别服务可能需要联网，也可能因系统、地区或企业策略而不可用。不可用时可以直接打字。

    本页面没有后端，也不保存音频。语音可能由浏览器发送给其语音服务处理。文字、草稿和记录保存在当前浏览器的本地存储中；更换浏览器、清除浏览数据或移动 HTML 文件可能无法看到原记录。可定期“导出备份”，再通过“导入记录”恢复。

    输入内容会自动保存。“先停一下”会生成可以继续的暂停记录；“保存这次记录”会保存整段练习。导出备份包含记录和当前草稿。

    在手机上使用

    也会尊重系统的“减少动态效果”设置。

    手机与电脑连接同一 Wi-Fi，双击电脑文件夹中的“手机访问.cmd”，在手机浏览器输入启动窗口列出的地址。请保持电脑和窗口开启；如果正在运行普通启动器，先关闭它。

    普通局域网 HTTP 地址支持文字练习、双语情绪表、动画和记录。网页长按语音需要 HTTPS，可改用手机键盘自带的麦克风。手机和电脑的记录各自保存在自己的浏览器中，可用备份转移。

    在释放环节轻触叶子，可观看放下的意象。选择“现在试一下”后也会播放；动画可跳过，支持“减少动画”和系统的减少动态效果设置。感受是否变化，仍由你自己体会。

    回到感受的几个提醒

    • 允许不是努力制造情绪；先看看能否少一点阻止和对抗。没有感觉，也可以先允许没感觉。
    • 先问能不能松开，再问愿不愿意。答案可以是真实的“不知道”，不用在头脑里答对。
    • 如果急着轻松释放、一次完成，可以把对释放结果的期待也当作练习目标。
    • 先靠近最近的感受。对情绪的抗拒、对状态的愧疚、对自己的责备，也可以先被看见。
    • 已有的安全、快乐与美好不用被赶走。探索的是“必须得到或必须保持”的紧抓，愿望与边界可以保留。
    • 放下内在紧绷不等于对外退让；沟通、行动和选择仍由自己决定。
    • 念头复杂时，先体会想到这句话时身体哪里有感觉，不必解释完所有原因。
    • 情绪再出现时，可以看看它是否更容易经过自己；不比较进度，也不要求到零、接纳或平静才允许结束。
    • 疲惫时可以休息。练习也可以只是欢迎感受、先停一下，不必把释放变成另一项任务。
